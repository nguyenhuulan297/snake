🐍 Supper Snake Game

Đây là trò chơi rắn săn mồi cổ điển được lập trình bằng C# trên visual studio. Đồ họa đẹp mắt, màu sắc dễ nhìn. Trò chơi cơ bản, dễ chơi kể cả những người ngu nhất.

🎮 cách chơi

-Dùng các phím mũi tên để di chuyển ăn mồi để đạt được số điểm cao nhất. Khi đâm vào tường hay cắn vào thân sẽ thua và kết thúc trò chơi.
-Giao diện console

🛠 Hướng dẫn cài đặt

1. Clone repository: git clone https://github.com/nguyenhuulan297/snake.git
2. Sử dụng phần mềm visual studio mở file có đuôi .slnx. Sau đó bấm F5 để chạy trò chơi
